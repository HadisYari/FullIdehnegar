# وب‌سایت ایده‌نگار (idehnegar.co)

پروژه‌ی Next.js سایت شرکت پیشگامان ایده‌نگار — دوزبانه (فارسی/انگلیسی)، سئو-محور، موبایل-اول، همراه با پنل مدیریت ساده برای نمونه‌کارها.

## پشته فنی

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4
- بدون دیتابیس: نمونه‌کارها در `src/data/portfolio.json` ذخیره می‌شوند (فایل‌محور، سبک و بدون نیاز به سرویس جداگانه)
- فونت‌ها به‌صورت لوکال (self-hosted) بارگذاری می‌شوند — بدون وابستگی به Google Fonts

## اتصال به بک‌اند (CMS)

محتوای سایت (نمونه‌کارها، خدمات، متن صفحات، تنظیمات شرکت، پیام‌ها و…) از
بک‌اند ASP.NET در پوشهٔ `../backend` می‌آید. همهٔ خواندن‌ها از یک لایه می‌گذرند:
`src/lib/cms.ts` — اگر API در دسترس نباشد، سایت به‌صورت خودکار از دادهٔ همراه
مخزن (`src/data/*.json` و literalهای کامپوننت‌ها) استفاده می‌کند تا هیچ‌وقت نشکند.

```bash
# در frontend/.env.local
CMS_API_URL=http://localhost:5100   # پورت backend/EndPoints (launchSettings.json)
CMS_REVALIDATE_SECRET=…             # همان مقدار Site:RevalidateSecret بک‌اند
CMS_REVALIDATE_SECONDS=60
CMS_TIMEOUT_MS=4000
```

- پنل مدیریت محتوا روی خود بک‌اند است: `http://localhost:5100/admin`.
- پس از هر ذخیره در پنل، بک‌اند `POST /api/revalidate` را صدا می‌زند تا کش ISR
  فرانت همان تگ‌ها را تازه کند.
- فرم تماس (`POST /api/contact`) اول در بک‌اند (SQL Server + ایمیل) ثبت می‌شود
  و فقط در نبود بک‌اند در `src/data/messages.json` می‌نویسد.
- برای توسعهٔ فرانت بدون دات‌نت/SQL Server: `node ../backend/tools/dev-api.mjs`
  همان قرارداد API را روی `SeedData/seed.json` اجرا می‌کند.

## اجرا روی سرور خودتان

### ۱) نصب و بیلد

```bash
npm install
npm run build
```

### ۲) تنظیم متغیرهای محیطی

فایل `.env.example` را کپی کنید و مقداردهی کنید:

```bash
cp .env.example .env
```

مقادیر لازم در `.env`:

| متغیر | توضیح |
|---|---|
| `ADMIN_USERNAME` | نام کاربری ورود به پنل مدیریت (`/admin`) |
| `ADMIN_PASSWORD_HASH` | هش رمز عبور ادمین — نحوه ساخت در بخش بعد |
| `SESSION_SECRET` | یک رشته‌ی تصادفی و طولانی برای امضای کوکی نشست. با دستور `openssl rand -hex 32` بسازید |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_SECURE` / `SMTP_USER` / `SMTP_PASS` | اختیاری — اگر پر شود، پیام‌های فرم تماس ایمیل می‌شوند. اگر خالی بماند، پیام‌ها فقط در `src/data/messages.json` ذخیره و در `/admin/messages` قابل مشاهده هستند |
| `CONTACT_TO_EMAIL` | ایمیلی که پیام‌های فرم تماس به آن ارسال می‌شود |
| `CONTACT_FROM_EMAIL` | آدرس فرستنده‌ی ایمیل (باید با تنظیمات SMTP شما سازگار باشد) |
| `NEXT_PUBLIC_SITE_URL` | آدرس نهایی سایت، مثلاً `https://idehnegar.co` — برای canonical، sitemap و structured data استفاده می‌شود |

### ۳) ساخت رمز عبور ادمین

```bash
node scripts/hash-password.mjs "رمز-قوی-دلخواه-شما"
```

خروجی این دستور را در `ADMIN_PASSWORD_HASH` در فایل `.env` قرار دهید.

### ۴) اجرای نسخه‌ی تولید (production)

```bash
npm start
```

به‌صورت پیش‌فرض روی پورت 3000 بالا می‌آید. توصیه می‌شود با یک process manager مثل PM2 اجرا شود تا در صورت ری‌استارت سرور، سایت هم خودکار بالا بیاید:

```bash
pm2 start npm --name idehnegar -- start
pm2 save
```

و در جلوی آن یک reverse proxy (Nginx) با گواهی SSL قرار دهید.

هر بار که کد یا محتوای متنی تغییر کرد، لازم است `npm run build` دوباره اجرا شود و سپس سرویس ری‌استارت شود. **اضافه/ویرایش/حذف نمونه‌کار از طریق پنل مدیریت نیازی به بیلد مجدد ندارد** — بلادرنگ روی سایت اعمال می‌شود.

## پنل مدیریت نمونه‌کارها

آدرس: `https://idehnegar.co/admin`

با نام کاربری و رمزی که در مرحله‌ی بالا ساختید وارد شوید. از این پنل می‌توانید:

- نمونه‌کار جدید اضافه کنید (تصویر + عنوان + توضیح فارسی/انگلیسی + دسته‌بندی + مشتری + سال + لینک)
- نمونه‌کارهای موجود را ویرایش یا حذف کنید
- پیام‌های ارسالی از فرم تماس را مشاهده کنید (`/admin/messages`)

تصاویر آپلودی به‌صورت خودکار فشرده و بهینه می‌شوند و در `public/uploads/portfolio/` ذخیره می‌شوند.

**نکته امنیتی:** پنل مدیریت با کوکی نشست امضاشده محافظت می‌شود و مسیر آن هیچ‌جا لینک نشده و `noindex` است. با این حال رمز عبور قوی انتخاب کنید و آن را در جای امنی نگه دارید.

## ساختار محتوا و متن‌ها

- متن‌های ثابت سایت (منو، عنوان بخش‌ها، دکمه‌ها و ...): `src/lib/i18n/dictionaries.ts`
- اطلاعات شرکت (آدرس، تلفن، ایمیل، آمار): `src/lib/site-config.ts`
- نظرات مشتریان: `src/data/testimonials.json`
- دسته‌بندی نمونه‌کارها: `src/lib/categories.ts`

## سئو

- عنوان/توضیحات و canonical/hreflang برای هر صفحه به‌صورت جداگانه تنظیم شده (فارسی بدون پیشوند در آدرس، انگلیسی با `/en`)
- داده‌ساختاریافته (JSON-LD) برای سازمان، لیست نمونه‌کارها و هر پروژه
- `sitemap.xml` و `robots.txt` به‌صورت خودکار و پویا تولید می‌شوند (شامل تمام نمونه‌کارها)
- تصاویر با `next/image` بهینه‌سازی می‌شوند

پس از انتقال به دامنه‌ی نهایی، مقدار `NEXT_PUBLIC_SITE_URL` در `.env` را حتماً به آدرس واقعی سایت تنظیم کنید، وگرنه لینک‌های canonical و sitemap اشتباه خواهند بود.
